# Changelog

## 0.1.0 — 2026-10-22

First public-ready implementation:

- Compare complete saved MCP tools/list contracts without connecting to servers.
- Separate conservative directional schema risks from concrete saved-input regressions.
- Validate arbitrary JSON structured results without reversing output-contract variance.
- Generate deterministic, value-redacted text, JSON and JUnit reports.
- Reject partial captures, duplicate identifiers, invalid schema definitions and unsupported references.
- Use strict local JSON Pointers and lossless decimal fixture parsing.
- Include synthetic passing/failing demos, offline-boundary tests, and Python CI configuration.

This is an early release. The CLI report envelope is versioned, but the project does not
promise complete JSON Schema compatibility analysis or long-term API stability.
